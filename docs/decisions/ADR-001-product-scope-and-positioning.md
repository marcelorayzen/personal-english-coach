# ADR-001: Product Scope and Positioning

## Status
Accepted

## Decision
The project is a personal English tutor by voice, single-user per installation, self-hosted/local-first.

It is not a SaaS product, not multi-tenant, and not a general-purpose assistant.

## Consequences
- architecture optimizes for clarity, not distributed scale
- configuration remains per installation
- product decisions prioritize pedagogical continuity
