# Spec: Progress Summary

## Goal
Provide simple and auditable progress visibility.

## Minimum metrics
- session count
- spoken minutes
- recurring issues
- skill trends
- recent focus areas

## Simple trends (Phase 5)
- compare current 7-day window vs previous 7-day window
- include direction: `up`, `down`, `stable`
- track at minimum:
  - spoken minutes trend
  - session trend
  - recurring issue trends by category
